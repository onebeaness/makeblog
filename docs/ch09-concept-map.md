## Tier 2. 회색지대 — 화면·코드로 **보여주고 설명은 안 한** 것

책의 스크린샷이나 SQL 코드에 분명히 등장하는데, 본문이 그냥 지나간 항목들.
"본 적은 있는데 뭔지는 모른다"가 정확히 회색지대다.

| # | 항목 | 어디서 나왔나 |
|---|---|---|
| 2-1 🔴 | `using` vs `with check` — 두 SQL이 다 나오는데 차이 설명이 없다 | 193쪽 / 205쪽 |
| 2-2 🔴 | `auth.uid()`는 대체 **어디서** 값을 가져오는가 | 203쪽 정책 코드 |
| 2-3 | Project Status의 **PostgREST**가 뭐길래 Healthy여야 하나 → Network 탭의 `posts?select=id,title` URL의 정체 | 185쪽 / 210쪽 |

| 2-5 | Anon Key와 Publishable Key가 "완전 호환"이라는 말의 실제 의미 | 188쪽 바이브 UP! |

| 2-7 | `schema_migrations` 테이블 — DB가 "어디까지 적용했는지"를 기억하는 방식 | 204쪽 |
| 2-8 | "보안 인증을 위한 **Server Actions**를 구현했습니다" — 이게 뭔가 | 188쪽 AI 응답 |

## Tier 3. 흑색지대 — 책이 **언급조차 안 했는데** 이 프로젝트가 의존하는 것

자가진단이 원천적으로 불가능한 영역. 이 목록 자체가 진단 도구다.

| # | 항목 | 왜 중요한가 |
|---|---|---|
| 3-1 🔴🔴 | **`service_role` 키의 존재** | 책에 한 글자도 안 나옴. 이 키는 RLS를 **전부 무시**한다. 실수로 클라이언트에 노출되면 앞의 RLS 작업이 통째로 무의미해진다 |
| 3-2 🔴🔴 | **UPDATE / DELETE 정책이 없는 채로 챕터가 끝난다** | RLS는 기본이 차단이므로 결과는 "아무나 지울 수 있다"가 아니라 **작성자 본인조차 수정·삭제할 수 없다**이다. A-4가 약속한 CRUD가 실제로는 CR에서 멈춘다. 진짜 위험은 나중에 수정·삭제를 붙이다 RLS 오류를 만나고, 가장 손쉬운 해법인 `using (true)`로 정책을 열어버리는 순간 발생한다 |
| 3-3 🔴 | **Next.js 캐싱 (`revalidate`, `router.refresh()`)** | 207쪽 "새 글이 메인에 안 보여요" 버그의 진짜 원인일 확률이 매우 높다. 책은 원인을 밝히지 않고 "AI에게 물어봐"로 넘긴다 |
| 3-4 🔴 | `'use client'`는 그 파일 아래 **import 트리 전체로 전파**된다 | 파일 하나에 붙인 줄 알았는데 그 아래 컴포넌트가 전부 클라이언트가 된다. B-7 실습에서 벌어진 일의 실제 메커니즘 |
| 3-5 | 무상태인데 **로그인 상태는 왜 유지되나** — 쿠키 / JWT / `@supabase/ssr` / 미들웨어 | 1-5(무상태)와 인증이 머릿속에서 충돌하는 지점. 대부분 여기가 비어 있다 |
| 3-6 | JWT의 구조, 만료, refresh token | "왜 갑자기 로그아웃되지"의 답 |
| 3-7 | **N:N은 실제로 조인 테이블로 만든다** (`likes` 테이블) | A-4에서 약속한 좋아요 기능을 직접 만들려면 반드시 필요. 책은 "다대다 관계 처리"라고만 쓰고 끝 |
| 3-8 | `on delete cascade` | 사용자를 지우면 그 사람 글은 어떻게 되나. 안 걸면 삭제 자체가 실패한다 |
| 3-9 | UUID vs 자동증가 정수 | 클라이언트에 id가 노출되는 구조에서 `/posts/1, 2, 3...` 순회(열거) 문제 |
| 3-10 | 인덱스 | 카테고리 필터·검색이 데이터가 쌓이면 느려지는 이유. A-4의 "풀텍스트 검색"이 여기 걸린다 |
| 3-11 | **마이그레이션은 되돌릴 수 없다** (down 마이그레이션이 없다) | 잘못 push하면 새 마이그레이션으로 고치는 수밖에 없다 |
| 3-12 | PATCH | 책은 PUT만 다룬다. 제목만 고치는 부분 수정은 원래 PATCH다 |
| 3-13 | CORS | 브라우저가 우리 도메인이 아닌 수파베이스 도메인으로 직접 요청하는데 왜 안 막히나 |
| 3-14 | Confirm Email을 끈 채 배포하면 | 남의 이메일 주소로 가입이 가능해진다. 책은 "실서비스에선 켜세요" 한 줄로 넘어간다 |
